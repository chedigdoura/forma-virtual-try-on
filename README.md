# Jihen Abbes Optique

Boutique vitrine responsive pour découvrir les lentilles de contact de Jihen Abbes Optique. Le catalogue propose recherche, tri par pertinence ou prix et filtres combinables par catégorie, marque, fabricant, période, type de lentille et disponibilité. Les photos du catalogue sont dans images/.

## Ouvrir le site

Ouvrir index.html dans un navigateur, ou lancer un serveur statique :

```bash
python -m http.server 8000
``

Puis visiter http://localhost:8000.

## Fichiers

- index.html — boutique et catalogue.
- admin.html — interface locale de gestion du catalogue.
- images/ — photos utilisées par les produits.

GitHub Pages publie le site depuis la branche main.
